# ClientBookThree
ClientBookThree is a desktop app that helps freelance software developers who work with many clients and collaborators keep track of the people involved in their projects. It is optimized for use with Command Line Interface (CLI) inputs through a Graphical User Interface (GUI).

## Features
- Manage clients
- Manage projects
- Assign clients to projects
- Group related clients together
